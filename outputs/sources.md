# Sources for the fee explainer

Official pages used as the retrieval corpus for `outputs/fee_explainer.md` (fee issue: **Paywalled usage limits**).
Page text was copied from each URL on 2026-10-21 and cached in `data/sources/`. The sandbox could not fetch
these pages itself because of Cloudflare bot protection, so the text was pasted in by the project owner and trimmed
to the article body (banners, login links, footers and tables of contents removed; links reduced to plain text).
